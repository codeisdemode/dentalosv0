DentalOS Documentation

DentalOS is het AI besturingssysteem voor tandartspraktijken. Deze docs geven je een helder overzicht van implementatie, API-koppelingen en operationele workflows.

Quickstart

  1. Maak een praktijkomgeving aan en configureer locatie-instellingen.
  2. Koppel agenda en EPD met de beschikbare connectors.
  3. Activeer communicatieflows voor reminders, recalls en escalaties.
  4. Monitor uitzonderingen in de live operations feed.
curl -X POST https://api.dentalos.ai/v1/practices \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Clinic Noord","timezone":"Europe/Amsterdam"}'

Autonome workflows

Planning, patiëntcommunicatie, declaraties en documentatie draaien continu op basis van praktijkregels en uitzonderingsroutes.

  • Herplanning, no-show opvolging en wachtlijstmatching op basis van agenda-capaciteit.
  • WhatsApp, telefoon en e-mail flows met automatische escalatie naar het team.
  • Consult output direct naar gestructureerde notities, acties en follow-up taken.

API Reference

REST API voor practices, appointments, claims en communications.

Endpoint Methode Doel
/v1/practices POST Nieuwe praktijk registreren
/v1/appointments GET Afspraken en status ophalen
/v1/communications/send POST Outbound bericht of call triggeren
/v1/claims/batches POST Declaratiebatch indienen

Authentication

Gebruik bearer tokens voor server-to-server calls.

Authorization: Bearer YOUR_API_KEY

Webhooks

Realtime events voor belangrijke praktijkacties.

  • appointment.rescheduled
  • communication.escalated
  • claim.exception.flagged
