# DentalOS

Static DentalOS landing site bundle.

## Structure

- `index.html`: standalone landing page
- `docs/`: standalone docs site
- `cards/`: embedded clinical card previews
- `images/`: local assets used by the landing page

## Local Preview

Serve the repository root with any static server, for example:

```bash
python -m http.server 4174
```

Then open `http://127.0.0.1:4174/`.
